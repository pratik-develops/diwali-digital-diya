# 🪔 Diwali Digital Diya

### A little light, a little love, a lot of happiness.

**Diwali Digital Diya** is an interactive, immersive digital celebration of the Festival of Lights. It brings together traditional Diwali stories, festive games, creative tools, personalised greetings, glowing diyas, fireworks and beautiful animations — all in one website.

🌐 **Live Website:** diwali-digital-diya.vercel.app

---

## ✨ About the Project

Diwali is more than a festival of lights. It represents hope, happiness, togetherness, courage and the victory of light over darkness.

Diwali Digital Diya aims to bring some of that festive magic into the digital world through an interactive experience where visitors can explore stories, play games, create greetings, design avatars and share their wishes.

The website combines traditional Indian festive elements with modern web technologies, animations and interactive experiences.

## 🚀 Features

### 1. 🪔 Interactive Festival Homepage
- Immersive Diwali-themed landing page.
- Beautiful festive visuals and animations.
- Interactive navigation to different experiences.
- Responsive layout for desktop and mobile devices.

### 2. 📖 Diwali Journey — Cinematic Storybook
Explore the meaning and stories behind Diwali through an interactive storybook.

- Ten chapters of storytelling.
- Stories covering Rama's return to Ayodhya, Maa Kali and the deeper meaning of light.
- Cinematic illustrations and page transitions.
- Interactive story navigation.

### 3. 🎮 Demon Slayer: Festival of Light
An exciting festive arcade adventure.

- Protect the kingdom.
- Unlock magical light powers.
- Fight enemies and progress through challenges.
- Chase high scores.
- Challenge friends to beat your score.

### 4. 🏮 Interactive Diya Garden
Bring a digital courtyard to life.

- Light individual diyas.
- Watch the courtyard glow.
- Light every diya at once.
- Reset the garden and start again.

### 5. 🎆 Fireworks Celebration
Celebrate Diwali with interactive fireworks.

- Trigger fireworks through clicks or touches.
- Enjoy festive sound effects.
- Interactive background fireworks.
- Toggle touch-triggered animations when needed.

### 6. 🎨 Rangoli Creator
Create your own digital rangoli designs.

- Choose from Lotus, Star and Mandala patterns.
- Experiment with different colour palettes.
- Download your creation.

### 7. 🏮 Wishes That Take Flight
Send your wishes into the digital night sky.

- Write a personal Diwali wish.
- Add your name optionally.
- Release your wish as a floating lantern.
- View your saved wishes.

**Note:** Wishes are currently stored locally in the browser using `localStorage`. They are not shared publicly between visitors.

### 8. 💌 Diwali Greeting Studio
Create personalised Diwali greetings through three creative modes:

**Greeting Card**
- Personalise sender and recipient names.
- Write custom messages.
- Choose Traditional, Emotional, Funny or Elegant styles.
- Select card templates, fonts, colours and stickers.
- Preview your card.
- Copy, share or download your greeting as a PNG.

**Secret Letter**
- Create a personal Diwali message.
- Share a link to your secret greeting.

**QR Greeting**
- Generate a QR code for sharing your greeting experience.

### 9. 👤 Design Your Diwali Avatar
Create a festive digital identity.

- Choose a character.
- Customise facial features and hair.
- Experiment with festive outfits and accessories.
- Select backgrounds.
- Download your avatar as a PNG.
- Save your look in the browser.

### 10. 📸 Diwali Camera
Capture your festive moments with Diwali-inspired filters.

- Access your device camera.
- Apply festive filters and visual effects.
- Capture and download photographs.
- Process photos directly in your browser.

Camera permission is requested before access begins. Photos are not automatically uploaded to a server.

### 11. 🎁 Mystery Gift Box
Every celebration deserves a surprise!

- Open the mystery gift box.
- Reveal a surprise blessing or festive message.

### 12. 🌍 Multilingual Experience
Explore the celebration in multiple languages:
- English
- Hindi
- Bengali

## 💻 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/pratik-develops/diwali-digital-diya.git
```

### 2. Navigate to the project directory

```bash
cd diwali-digital-diya
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the website

Visit:

```text
http://localhost:3000
```

The development server will automatically refresh when you make changes to the source code.

### Production Build

To create a production build:

```bash
npm run build
```

To start the production server after a successful build:

```bash
npm run start
```

## ⚙️ Important Usage Notes

### Performance Tip — Touch Animations

**If the website hangs, becomes slow, or starts lagging, simply turn OFF the `Touch Animations` toggle in the top navigation.**

This disables the background fireworks triggered by touching or clicking the website background and can help reduce animation-related workload, particularly on lower-end devices.

You can turn it ON again whenever you want to enjoy the full interactive experience.

### Camera Access
- Camera functionality requires browser permission.
- Use HTTPS for camera access on deployed websites.
- If the camera does not open, check your browser's camera permissions.
- Photos are processed in the browser and are not automatically uploaded.

### Browser Storage
Some experiences use browser `localStorage` to save data, such as:
- Floating wishes.
- Avatar settings.
- Other locally stored preferences.

This means locally saved content may not automatically appear on another device or browser.

### Audio
Some sound effects require an initial user interaction because browsers restrict automatic audio playback.

## 🔒 Privacy

The project is designed to provide its interactive experiences directly in the browser.

- Camera access requires explicit browser permission.
- Camera photos are not automatically uploaded.
- Avatar settings and floating wishes are stored locally.
- The current project does not provide a shared public wishes database.
